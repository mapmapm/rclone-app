Rclone Personal Application

Application Type: Personal use only
Number of Users: 1 (personal)
Purpose: File synchronization with Google Drive

About This Application

This is a personal application created for my own use to synchronize files between my local Fedora Linux server and my Google Drive storage.

The application uses the Google Drive API through Rclone, an open-source command-line program to manage files on cloud storage.

What This Application Does

  • Reads and writes files to my personal Google Drive
  • Synchronizes media files for personal streaming
  • Creates encrypted backups of personal data

What This Application Does NOT Do

  • Does not collect any user data
  • Does not share data with third parties
  • Does not track user activity
  • Does not use cookies or analytics
  • Is not available for public use

Technical Details

This application runs on a personal Linux server and uses OAuth 2.0 authentication to access Google Drive. All operations are performed locally and no data is transmitted to any server other than Google's own infrastructure.
